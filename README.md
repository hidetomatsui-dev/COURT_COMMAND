# COURT COMMAND（コートコマンド）

5人制バスケットボールを題材にした、ターン制の戦略カードゲームのプロトタイプです。
選手は直接動かさず、5人の組み合わせと作戦で相手の守備にズレを作ります。1試合3〜5分。

既存のデジタル選手カードのコレクションに「集めたカードで考えて戦う」遊びを追加する、という提案のための試作版です。登場する選手・クラブはすべて架空です。

## 遊び方

`index.html` をブラウザで開くだけで動きます。サーバーやビルドは不要です。

GitHub Pages で公開している場合は、次のURLで遊べます。

https://hidetomatsui-dev.github.io/COURT_COMMAND/

## 主な仕組み

- 年俸100以内で5人を編成し、作戦カード5枚を持ち込む
- 毎ターン、攻め（作戦・起点の選手・相手役）と守り（守備方針）を同時に決める
- シュートの質は運なしで決まり、成否だけを公開されたチップ袋から引いて決める
- 同じ作戦を続けると「読まれ度」がたまり、通りにくくなる
- 流れゲージ、タイムアウト、最後の攻撃権、オフェンスリバウンド、スタミナ
- CPUも同じルールで戦い、選手・作戦はすべて公開
- カードのレア度は見た目と特性のバリエーションだけで、試合の強さは変わらない

## データの保存

コレクションや成績は、ブラウザの localStorage に保存されます（端末・ブラウザごと）。
